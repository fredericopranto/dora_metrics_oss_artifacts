# Replication Package: Evaluating Software Delivery Performance: A DORA Metrics-Based Comparison of ML and non-ML Projects on GitHub

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.XXXXXXX.svg)](https://doi.org/10.5281/zenodo.XXXXXXX)

This repository contains the replication package and supplementary materials for the paper **"Evaluating Software Delivery Performance: A DORA Metrics-Based Comparison of ML and non-ML Projects on GitHub"**, submitted to the Mining Software Repositories (MSR) conference.

## 📌 1. Artifact Purpose
This artifact provides the supplementary data and documentation used to answer the Research Questions (RQs) presented in our study. It includes visual charts for the quantitative analysis (RQ1 and RQ2), the XML files used for the qualitative thematic coding (RQ3), and detailed methodological documentation regarding the collection and calculation of DORA metrics in Open Source Software (OSS).
